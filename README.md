# Demoshots releases

Beta downloads for Demoshots, a macOS menu bar app that records a demo and turns it into a note.

- Download page: https://kiancjy.github.io/demoshots-releases/
- Latest DMG: see `appcast.xml` or the newest `Demoshots-<version>.dmg` in this folder.
- The app checks this folder for updates once a day through Sparkle.

`Demoshots-<version>.dmg`, `Demoshots-<version>.html`, and `appcast.xml` are generated by `scripts/release.sh`
in the app repo. Do not edit them by hand.

`index.html` and `install-open-anyway.png` are hand-made. `index.html` names the current version, the DMG size,
and the DMG link in three places, each marked with a `RELEASE:` comment. Update those three lines when a new
DMG lands here.
