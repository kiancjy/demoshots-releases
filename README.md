# Demoshots releases

Beta downloads for Demoshots, a macOS menu bar app that records a demo and turns it into a note.

- Latest DMG: see `appcast.xml` or the newest `Demoshots-<version>.dmg` in this folder.
- Install guide: https://github.com/kiancjy/demoshots-app/blob/main/docs/install.md (private during beta - the DMG ships with the same note).
- The app checks this folder for updates once a day through Sparkle.

Files here are generated by `scripts/release.sh` in the app repo. Do not edit by hand.
